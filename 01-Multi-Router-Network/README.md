# Multi-Router Network

## Overview

A multi-router network topology implemented using Cisco Packet Tracer.

## Topology

The network consists of:
- 3 Routers
- 3 Switches
- 3 PCs
- Multiple IPv4 networks

## Network Configuration

- IPv4 addressing
- Router-to-router connectivity
- LAN connectivity
- End-to-end connectivity testing

## Verification

Connectivity was verified using ICMP ping tests between the end devices.

## Tools

- Cisco Packet Tracer
