# Multi-Router Network

A practical multi-router network lab implemented using Cisco Packet Tracer during my Network Security Summer Training.

## Overview
This lab demonstrates how multiple routers connect different networks and provide connectivity between them.

## What I Practiced
- IP addressing and subnetting.
- Connecting multiple routers and switches.
- Routing between different networks.
- Configuring DHCP, DNS, and HTTP services.
- Testing connectivity between devices.

## Network Topology
The lab consists of three routers, three LANs, and two router-to-router connections. It also includes PCs, switches, and servers providing DHCP, DNS, and HTTP services.

## Tools
- Cisco Packet Tracer
